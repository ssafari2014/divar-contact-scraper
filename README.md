# 📞 Divar Contact Scraper

A Python script that scrapes phone numbers from Divar.ir ads based on a keyword using Selenium and saves them to an Excel file.

---

## 🔍 Features

- 🔎 Search Divar for any keyword
- 📄 Click into each ad
- ☎️ Automatically reveal and collect phone numbers
- 💾 Save all numbers and titles in an Excel (.xlsx) file

---

## 🚀 Technologies Used

- Python 3.x
- Selenium
- pandas
- openpyxl
